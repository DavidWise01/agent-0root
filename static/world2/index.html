▪ THE FACTORY // the training story — GENERATION & SAMPLE

TRAIN The factory reads I-13 source as a corpus and learns exactly one thing — a character bigram (the only weights). A sub-agent samples fresh code from it; alone, it babbles broken brackets. Then two zero-parameter structural operators clamp it well-formed: the VETO (a pushdown automaton — forbids the wrong closer) and −I DISCHARGE (closes each opener under rising pressure, drains the rest at the end). The learned model gives texture; structure gives correctness. It runs live below — deep floor: the full factory.

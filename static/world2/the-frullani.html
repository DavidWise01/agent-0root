THE FRULLANI

an integral that reads only its endpoints
1 WHAT IT IS · WHAT IT DOES · FACT OR FICTION
The Frullani integral is an integral that ignores almost everything about the function inside it. For a nice function f, ∫0∞ (f(ax) - f(bx))/x dx = (f(0) - f(∞))·ln(b/a). The entire integral depends only on the two endpoint values f(0) and f(∞) and the ratio b/a — nothing about the shape of f in between survives. Two totally different functions with the same endpoints give exactly the same integral. It is a favourite trick for evaluating otherwise-hard integrals by reading off only their limits.

LIT verified live by numerical integration: for f(x)=e-x and for f(x)=e-x² — two very different functions sharing f(0)=1, f(∞)=0 — the integral ∫(f(ax)-f(bx))/x dx equals ln(b/a) for several a,b, to ~1e-6 (window.__frullani).

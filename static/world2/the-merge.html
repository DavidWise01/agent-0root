LIT A genuine 3-way line merge, the algorithm behind git merge. For each line it compares OURS and THEIRS to the BASE: if only one side changed, take that side; if both made the same change, take it; if both changed it differently, it's a CONFLICT (marked <<< ours | theirs >>>).

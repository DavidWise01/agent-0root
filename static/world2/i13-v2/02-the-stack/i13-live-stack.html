What is running. The sub-agent is an eight-head attention stack with a 13-character window and one hidden layer — 18,249 trained parameters, exported and executing in this page. The cortex is five rules with zero parameters. Everything amber in the output was written by the cortex, not proposed by the model.

Turn the cortex off and watch it fail. Line numbers stop rising, parentheses stop closing, and PRINT repeats until the window fills with it. Each of those is something a 13-character window structurally cannot hold: a counter, a stack, an identity. Training does not fix them — four separate attempts are documented in the build, and the only one that moved was reweighting the loss.

The address rule is the sharpest case. A BASIC line number is not content, it is an address. The model scored 51% monotonic on its own — chance. Handing the decision to the cortex outright, rather than constraining the model toward it, gives 99%, and the 1% is a program boundary where a reset is correct.

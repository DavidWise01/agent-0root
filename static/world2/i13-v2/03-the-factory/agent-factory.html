What it does. Reads arbitrary source, profiles it against 41 languages by character trigram and delimiter density, names the family, measures the depth entropy of the corpus, and emits everything an agent needs to start: which plane to boot at, which delimiter pairs to guard, which of the five cortex rules to equip, and what safety margin to dispatch with.

Family is what matters, not the name. Exact identification is 82.9% on held-out source; family is 95.1%. WASM identifies as “lisp” at a margin of 0.0003 and Rust as “swift” — both wrong names, both the right family, both the right equipment. The pair table and the rule set are per-family, so a family hit is a correct ship.

The note is the point. Each bootloader carries the trap that language actually sprang during the build. FORTRAN's says never to collapse the card columns — doing that dropped a working agent from 54% to 16% and cost three turns of chasing rules that were wired to a signal already deleted. BASIC's says the line number is an address the cortex must write outright: constraining the model toward monotonic numbers instead produced 44-digit runaways, while handing it over gives 99%.

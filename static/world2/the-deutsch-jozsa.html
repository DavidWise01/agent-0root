THE DEUTSCH-JOZSA

constant-or-balanced in one question
1 WHAT IT IS · WHAT IT DOES · FACT OR FICTION
The Deutsch–Jozsa algorithm answers a yes/no question about a black box in a single query where classical certainty may need over half of all inputs. You are promised a function f:{0,1}n→{0,1} is either constant (same output everywhere) or balanced (0 on exactly half, 1 on the other half). Superpose all inputs, let the oracle stamp the phase (−1)f(x), and Hadamard again: the amplitude at |0…0⟩ becomes (1/2n)∑x(−1)f(x) — magnitude 1 if constant, exactly 0 if balanced. One measurement decides.

LIT verified live: simulating the amplitude, every constant function gives |amplitude at |0…0⟩| = 1 and every balanced function gives 0 (window.__deutsch_jozsa), from one oracle call — classically the worst case needs 2n−1+1.
